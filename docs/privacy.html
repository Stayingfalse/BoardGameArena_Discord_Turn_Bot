Privacy Policy

BGA Turn Bot · Last updated: 2026/10/11

This Privacy Policy explains what data BGA Turn Bot (the "Bot") reads and stores, why, who can see it, and how to remove it. The Bot is a self-hosted Discord bot that watches public Board Game Arena (BGA) tables and codenames.game rooms and posts game and turn updates in Discord. It is run by an independent operator (contact details below), who controls the data described here.

1. What the Bot reads

  • Messages in channels it can see. The Bot reads new and edited messages to spot BGA table links. It does not store message text: it only keeps the table ID it found. If a server enables "tidy up shared links", the Bot deletes the message containing the link once its own table message has replaced it.
  • Public BGA pages. The Bot reads public table pages in spectator mode, without a BGA account, cookies or credentials.
  • Codenames rooms. The Bot also spots codenames.game room links (keeping only the room ID) and joins those rooms as a spectator. Like every visitor, it then appears in the room's player list, under a name starting with 🤖, and receives what any spectator sees: the names people chose in the room, the teams, clues and revealed cards. It never joins a team and does not see the hidden card colours.

2. Data we store

The Bot stores the following in a local database on the server where it runs:

  • Discord identifiers: server (guild), channel and message IDs, and the user IDs of linked members and of whoever shared a table link.
  • BGA account links: the public BGA player name and/or ID linked to a Discord member, either by the member themselves (the "Link your BGA & Discord" button) or by a server admin. Links are global: a link made in one server applies in every server that uses the same Bot.
  • Watched tables: table IDs and URLs, the game, the public names and IDs of the players at the table, seats, whose turn it is, and the Bot's message for that table.
  • Game history: when a watched table ends or stops being watched, a record is kept of the game, server, channel, who shared the link, when it started and ended, how it ended, and the winners and final standings (public BGA player names and scores). This history is used for statistics.
  • Codenames rooms: room IDs, the credentials and name the Bot uses in each room, the names people chose in the room, which Discord member claimed which name (with the "I'm playing" button), members asked to play with /codenames players, each member's last claimed name (offered as a suggestion next time), and the state of each game and the Bot's messages for it. Finished Codenames games are kept in the game history with the winning team.
  • Server settings chosen by server admins.
  • Dashboard logins (only if the operator enables the web dashboard): when you log in with Discord, your user ID, username, avatar and the list of servers you belong to (with your permissions there). Login sessions expire after one day or when you log out, and use a single session cookie.
  • Logs: the operator's server logs record Bot activity, including which Discord user ran which command.

The Bot does not collect email addresses, passwords, payment information or BGA login credentials.

3. How the data is used and who can see it

The data is used only to run the Bot: posting and updating table and game messages, mentioning linked players when it is their turn, and showing statistics. It is not used for advertising or profiling.

  • Within a server, members can see table messages and that server's statistics (/bga stats), which include BGA player names, games played, wins and who shared tables. Server admins can also see these, and the server's member links, on the dashboard.
  • Codenames game messages show the names chosen in the room, which Discord member claimed each name, and the members asked to play; anyone who can read the channel sees them. The dashboard and /codenames status show the server's watched rooms and Codenames totals.
  • Across servers, global statistics (the dashboard's public pages and /bga stats global) show only totals and game titles. They do not show player names, Discord users, channels or Codenames room links.
  • The operator, and any global admins they appoint, can see all stored data.

4. Where the data is stored

All data is stored in an SQLite database file on the server run by the operator. It is not sold, rented or shared with third parties, and it is not sent to analytics or advertising services.

5. Retention and deletion

  • Your BGA link: click "Link your BGA & Discord" on any table message and choose Unlink. Server admins can also remove it with /bga unlink-member or on the dashboard.
  • Watched tables are removed automatically when the game ends, and server admins can stop watching a table from the dashboard.
  • Codenames: press "I'm playing" on a game message and choose I'm not playing to remove your claim on a name. A room stops being watched when nothing has happened in it for a while (7 days by default), when the Bot can no longer reach it, or with /codenames unwatch; its game messages are then no longer updated. The names seen in a room and the Bot's credentials for it are kept so the Bot can recognise the room if it is posted again; contact the operator to have them deleted.
  • When the Bot is removed from a server, the Bot stops watching that server's tables and Codenames rooms and deletes its settings. Game history, including those tables, is kept for statistics until the operator deletes it.
  • For any other deletion request, including game history, contact the operator.

6. Third-party services

The Bot operates on Discord, reads public data from Board Game Arena and joins codenames.game rooms as a spectator; it is not affiliated with any of them. Your use of Discord is governed by Discord's Privacy Policy, and your use of Board Game Arena and codenames.game by their own privacy terms. If the dashboard is enabled, pages with charts load a chart library from the jsDelivr CDN, and avatars and server icons are loaded from Discord's CDN, so those services see your browser's request.

7. Children

The Bot is intended to be used within Discord, which requires users to be at least 13 years old (or the minimum age of digital consent in their country). The Bot is not directed at children below that age.
